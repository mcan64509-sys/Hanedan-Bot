# HANEDAN BOT

Railway Variables:

TOKEN=Discord bot token
CLIENT_ID=Discord application ID
GUILD_ID=Discord server ID
WELCOME_LOG_CHANNEL_ID=Gelen/giden mesajlarının gideceği METİN kanal ID'si
YOUTUBE_COOKIES=Get cookies.txt LOCALLY ile aldığın YouTube cookies.txt içeriğinin tamamı
BOT_FOOTER=İsteğe bağlı override. Varsayılan: HANEDAN BOT • Created By Lymix

Discord Developer Portal:
- Bot > Privileged Gateway Intents > SERVER MEMBERS INTENT = ON
- Bot ses için Connect + Speak, metin için Send Messages + Embed Links izinlerine sahip olmalı.
- Administrator verirsen izin tarafı zaten tamamdır.
